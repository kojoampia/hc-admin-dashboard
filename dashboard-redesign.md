### Operation Dashboard Redesign

The dashboard must be redesigned to provide a more intuitive and user-friendly experience for operators only.
The new design focuses on improving navigation, enhancing visual appeal, and providing better access to key operational features.

**Key changes include:**

- **Simplified Navigation**: The navigation menu has been streamlined to reduce clutter and make it easier for users to find what they need.
- **Enhanced Visuals**: The dashboard now features a cleaner layout with improved typography and color schemes to enhance readability and user engagement.
- **Quick Access Widgets**: New widgets have been added to provide quick access to frequently used features and important metrics, allowing operators to stay informed and take action more efficiently.
- **Responsive Design**: The dashboard is now fully responsive, ensuring a seamless experience across all devices, from desktops to mobile phones.
- **Removed Non-Operational Features**: Features that are not relevant to operators must be removed to declutter the interface and focus on essential operational tools.
- **Focus on Operations**: The redesign emphasizes operational features, ensuring that operators can easily access and utilize the tools they need to perform their tasks effectively.

This redesign aims to enhance the overall user experience for operators, making it easier for them to navigate the dashboard and access the tools they need to perform their tasks efficiently.

**Target Dashboard:**

`/src/webapp/app/entities/dashboard`
Operator Dashboard is located at: `src/webapp/app/entities/dashboard/dashboard-component.{ts,html,scss}`.
Do not stray outside of this directory when implementing the redesign, as the focus is solely on the operator dashboard.
`/src/webapp/app/widgets` widgets can be used when implementing the new metrics for the dashboard, but do not modify any existing widgets in this directory as they may be used by other dashboards or features within the application.
