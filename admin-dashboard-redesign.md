# Admin Dashboard Redesign

**Role**:
Act as a UI/UX designer tasked with redesigning the admin dashboard for a web application. The goal is to improve usability, enhance visual appeal, and ensure that the dashboard provides a seamless experience for administrators managing their tasks.

**Objectives**:

1. **Improve Usability**: Simplify navigation, enhance readability, and ensure that administrators can easily access and manage key functionalities.
2. **Enhance Visual Appeal**: Update the visual design to be modern and aesthetically pleasing, using consistent color schemes, typography, and iconography.
3. **Optimize Layout**: Organize information logically, prioritize critical data, and provide customizable views to cater to different administrative needs.
4. **Ensure Responsiveness**: Design the dashboard to be fully responsive, providing a seamless experience across various devices and screen sizes.
5. **Integrate Real-time Data**: Ensure that the dashboard can display real-time data and updates, allowing administrators to make informed decisions quickly.

**Deliverables**:

- Each Widget should have a set window modifiers for maximising, minimizing, and closing the widget.
- Each Widget should expand to fill the entire dashboard when maximized, and return to its original size and position when minimized.
- Each Widget should have a close button that removes the widget from the dashboard when clicked.
- The dashboard horizontal grid should have a maximum of 1 widget per row.
- The dashboard should have a vertical grid with a logical grouping of widgets based on their functionality (e.g., user management, analytics, settings).
- The dashboard should include a sidebar for easy navigation between different sections (e.g., Home, User Management, Analytics, Settings).
- The dashboard should have a top navigation bar that includes the application name, user profile, and quick access to each widget.
- Each button should an icon that visually represents its function (e.g., maximize, minimize, open, close) and should be easily identifiable and accessible.
- The dashboard should be fully responsive, providing a seamless experience across various devices and screen sizes, ensuring that all functionalities are accessible and usable on mobile devices, tablets, and desktops.

**Task**:

1. Fix the layout of the dashboard to ensure that each widget is properly aligned and spaced, adhering to the maximum of 1 widget per row.
2. Implement the window modifiers for each widget, allowing administrators to maximize, minimize, and close widgets as needed.
3. Design a sidebar for easy navigation between different sections of the dashboard, ensuring that it is intuitive and accessible.
4. Create a top navigation bar that includes the application name, user profile, and quick access to each widget, ensuring that it is visually distinct and functional.
5. Ensure that the dashboard is fully responsive, providing a seamless experience across various devices and screen sizes.

**Build Instructions**:

1. Use the current frontend framework Angular 19, Angular Material, and Tailwind CSS to implement the redesign.
2. Follow best practices for UI/UX design, ensuring that the dashboard is user-friendly and visually appealing.
3. Test the dashboard on various devices and screen sizes to ensure responsiveness and usability.
4. Test thoroughly to ensure that all functionalities, including the window modifiers and navigation, work as intended without any bugs or issues.
5. Document the design decisions and implementation details for future reference and maintenance in a comprehensive report.

Start in `src/webapp/app/admin/dashboard` and implement the redesign according to the objectives and deliverables outlined above.
